# VectorLab AI Bible

Questa e la prima bozza della conoscenza derivata dalle trascrizioni IBM.

## Principi editoriali

- distinguere fatti, principi, esempi e opinioni;
- preferire spiegazioni operative a slogan;
- indicare limiti, rischi e condizioni di validita;
- mantenere la provenienza delle idee;
- trattare le news come contenuto temporale, non come verita permanente.
